# 🐍 Практика по основам Python

В этом репозитории собраны мои учебные задачи и мини-проекты, выполненные в процессе изучения языка Python. Код разбит по темам от базового синтаксиса до написания алгоритмических функций.

## 📂 Содержание репозитория

* **`01_strings_and_io/`** — форматирование строк, срезы, методы `.replace()`, `.split()`, `.index()`, пользовательский ввод.
* **`02_data_structures/`** — работа со списками (`list`), кортежами (`tuple`) и словарями (`dict`), перебор ключей и значений.
* **`03_loops_and_conditions/`** — циклы `for` и `while`, функция `enumerate()`, генерация чисел и простая игра «Угадай число».
* **`04_applied_tasks/`** — решение практических задач с использованием функций:
  * *Поиск победителей розыгрыша* (работа с индексами и счётчиками).
  * *Гонка зайца и черепахи* (сравнение сумм элементов списков).
  * *Планировщик рабочего дня* (подсчёт остатка времени).
  * *MVP Dating-сервиса* (сортировка и объединение списков через `zip`).
  * *Поиск палиндромов* (обработка строк и срезы).
  * *Калькулятор списка покупок* (работа со вложенными списками и расчёт пропорций).

## 🛠 Стек технологий
* Python 3.x
* Стандартная библиотека Python (`statistics`)
